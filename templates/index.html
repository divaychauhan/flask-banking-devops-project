DevOps Implementation

Phase 1 — Flask Application

Built a Python Flask banking app with account creation, deposit, withdraw, transaction history, and health check route.

Skills: Python, Flask, Backend Routing

Phase 2 — AWS RDS MySQL

Created a new RDS MySQL database and connected the app using environment variables.

Skills: RDS, MySQL, Security Groups

Phase 3 — Dockerization

Created Dockerfile, built the image locally, tested the container, and pushed the image to Docker Hub.

Skills: Dockerfile, Image, Container

Phase 4 — EC2 Deployment

Pulled the Docker image on Ubuntu EC2 and ran the app container with environment variables from the server.

Skills: EC2, Linux, Docker Run

Phase 5 — CI/CD Pipeline

Configured GitHub Actions to build, push, and deploy Docker images based on dev, test, and main branches.

Skills: GitHub Actions, CI/CD, Automation

Phase 6 — Monitoring & Logs

Used Docker logs, curl, MySQL CLI, and health check endpoint for troubleshooting.

Skills: Logs, Debugging, Health Checks

Useful Production Commands
